# tools.molyuk.com

Набор повседневных инструментов разработчика: генерация ID, хэши, base64 и другое.
Почти всё считается локально в браузере; единственное исключение — «Мой IP»
(`compute: 'edge'`), которому нужен воркер, чтобы увидеть адрес клиента.

Стек: Vue 3 + Vite + TypeScript + Tailwind CSS. Интерфейс двуязычный (ru/en) на vue-i18n.
Деплой — Cloudflare Workers: воркер отдаёт статику и обслуживает единственную ручку
`/api/ip` (`worker/index.ts`).

## Разработка

```sh
npm install
npm run dev
```

## Добавление нового инструмента

Каждый инструмент — папка в `src/tools/<slug>/` с файлом `index.ts`:

```ts
import { defineAsyncComponent } from 'vue'
import type { ToolMeta } from '../types'

export const meta: ToolMeta = {
  slug: 'my-tool',
  nameKey: 'tools.myTool.name',
  descriptionKey: 'tools.myTool.description',
  categoryId: 'converters',
  order: 14,
  compute: 'client',
}

export const component = defineAsyncComponent(() => import('./MyTool.vue'))
```

Поля `ToolMeta` (`src/tools/types.ts`):

| Поле             | Значение                                                                       |
| ---------------- | ------------------------------------------------------------------------------ |
| `slug`           | Имя папки; из него собирается маршрут `/tools/<slug>`                          |
| `nameKey`        | Ключ i18n для названия — не сам текст                                          |
| `descriptionKey` | Ключ i18n для описания                                                         |
| `categoryId`     | `identifiers` \| `encoding` \| `text` \| `network` \| `converters` \| `data`   |
| `order`          | Сквозной номер по всему сайту — виден на карточках главной как `01`, `02`, …   |
| `compute`        | `client` (в браузере) или `edge` (нужен воркер)                                |

Инструмент автоматически появится в навигации и на главной странице (`src/tools/registry.ts`
сканирует папку через `import.meta.glob`) — роутер и меню трогать не нужно.

### Про `order`

Номер отображается пользователю, и внутри категории инструменты идут по нему же.
Поэтому нумерация должна оставаться **сплошной от 01** и сгруппированной по категориям
в порядке `CATEGORY_ORDER` из `registry.ts`. Вставка инструмента в середину означает
сдвиг номеров у всех, кто идёт после, — это одна строка в каждом `index.ts`.

### Строки интерфейса

Тексты живут в `src/i18n/messages.ts` — блок `tools.<camelCaseSlug>` нужно добавить
**в обе локали, `ru` и `en`**. Тип `MessageSchema` выведен из `ru`, так что забытый
английский ключ ловится `vue-tsc` на сборке; забытый русский — нет, он просто
отрендерится как сырой ключ. Ключи, которые шаблон собирает динамически
(например `` t(`tools.cidr.scope_${scope}`) ``), тайпчекер не проверяет вовсе —
их стоит перепроверить руками.

### Компонент

Компонент инструмента оформляется в `<slug>/<Name>.vue` и собирается из общих блоков
в `src/components/`:

| Компонент          | Назначение                                                          |
| ------------------ | ------------------------------------------------------------------- |
| `ToolPage.vue`     | Обёртка страницы: заголовок, описание, отступы                      |
| `ToolPanel.vue`    | Панель параметров над результатом                                   |
| `OutputBar.vue`    | Полоса «Вывод» со статусом и кнопками копирования/скачивания        |
| `CopyButton.vue`   | Копирование в буфер (опционально вместе с картинкой)                |
| `DownloadButton.vue` | Скачивание результата файлом                                      |

Чистую логику (парсинг, арифметику) лучше держать в отдельном `.ts` рядом с компонентом —
так её можно переиспользовать и проверить. Примеры: `src/tools/ip-list/ip.ts` с разбором
IPv4/IPv6, который использует и генератор списков, и CIDR-калькулятор;
`src/tools/color/color.ts` с матрицами OKLab.

Если инструмент выполняет то, что ввёл пользователь (регулярное выражение, шаблон, формулу),
это должно уходить в Web Worker с таймаутом — см. `src/tools/regex/`. Регулярку нельзя
прервать: `(a+)+b` на тридцати символах считается около минуты, и в основном потоке это
намертво вешает вкладку. Из воркера поток можно просто убить.

## Сборка и деплой

```sh
npm run build          # проверка типов + продакшн-сборка в dist/
npm run worker:dev      # локальный запуск как Cloudflare Worker (wrangler dev)
npm run deploy          # сборка + wrangler deploy
```

Деплой требует авторизации в Cloudflare: `npx wrangler login`.
